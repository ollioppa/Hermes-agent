Delivery Workflow

Turn a scoped idea or substantial change into working software, use instructions and saved evidence. The host agent does the work; a small Python coordinator records and validates progress.

Agree on outcome → Design and build → Check the actual result → Hand over evidence

When it helps

Use it for uncertain, connected work or work resumed across sessions. A small known edit or read-only question usually needs only an ordinary request. This workflow adds explicit scope, phase evidence and resumption, not better model intelligence or automatic deployment.

Prepare once

Load SKILL.md with a harness that can read files, edit the authorized project and run tools. No universal skill installation path or slash command is assumed. Provide Python 3.10+, PyYAML, jsonschema and Git. Choose private records and configuration paths outside every Git ancestor and outside this package.

The project may be empty. Reuse existing requirements and design; ask about unresolved material choices rather than repeating approvals. Do not equate authorization to build a destructive tool with permission to run it live.

Work and resume

Audit a private task, perform each included phase in order, and immediately record its real evidence. Status returns the next assignment after interruption. Required phases are understand, verify and postmortem; other phases need either execution or an allowed, evidenced exclusion. An invalidated experiment stops downstream work.

What completion means

Check validates records and writes a private report, including when --dry-run is supplied. Complete means evidence completion, not semantic correctness, independent review, deployment or publication. A required independent reviewer must actually be independent. Human authorization remains necessary at material permission boundaries; inaccessible checks remain open.

First use is blocked?

Check the exact missing dependency, file access or harness capability. A private folder within any Git ancestor is rejected even if ignored. Ask for an authorized compliant location; do not weaken that guard or silently choose another root. Run a small recipient-host pilot before relying on integration or compatibility claims.
